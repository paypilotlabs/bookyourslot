# Security Policy

Found a vulnerability in BookYourSlot? Report it privately: open this repository's **Security** tab and choose **Report a vulnerability**. Please don't open a public issue.

Include steps to reproduce, the affected route or component, and the commit or release you tested. Use test data, not real customer bookings.

Only the latest release and `main` receive security fixes. Reports are handled by the PayPilotLabs maintainers on a best-effort basis.
